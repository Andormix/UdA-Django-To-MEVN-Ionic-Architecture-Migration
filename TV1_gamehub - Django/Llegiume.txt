DESCRIPCIÓ
----------
GameHub és la plataforma web oficial per al videojoc del nostre TFG.
Centralitza el devlog de desenvolupament, la comunitat de jugadors
i una botiga d'items/moneda virtual (skins, diamants, monedes).

Construïda amb Django 5.2 seguint els patrons del llibre
"Django 5 By Example" (5a edició) d'Antonio Melé.

REQUISITS DEL SISTEMA
----------------------
- Docker Desktop (Windows/Mac/Linux)
- Docker Compose v2
- Python 3.12+ (per executar localment sense Docker)

INICI RÀPID - DOCKER DESKTOP
------------------------------
1. Obrir Docker Desktop
2. Obrir un terminal a la carpeta TV1_gamehub/
3. Construir la imatge:
   ./do.sh build o docker compose build

4. Iniciar el servidor:
   ./do.sh start o docker compose up web_run

5. Accedir a: http://localhost:8000

PRIMERA CONFIGURACIÓ
---------------------
Crear superusuari (per accedir al panell d'admin):
   	docker compose exec web_run python manage.py createsuperuser

URLS PRINCIPALS
---------------
  /                     - Devlog (pàgina principal)
  /account/login/       - Inici de sessió
  /account/register/    - Registre d'usuari
  /account/             - Tauler de control
  /social/              - Comunitat
  /shop/                - Botiga
  /cart/                - Cistella
  /orders/order/create/ - Finalitzar compra
  /api/                 - API REST (DRF browsable)
  /admin/               - Panell d'administració
  /devlog/feed/         - RSS Feed del devlog

API REST ENDPOINTS
------------------
  GET /api/posts/        - Llistat de posts publicats
  GET /api/posts/{id}/   - Detall d'un post
  GET /api/comments/     - Llistat de comentaris actius
  GET /api/comments/{id}/ - Detall d'un comentari

COMANDES ÚTILS SI VOLS UTILITZAR-LES ALFRED
--------------
  ./do.sh build          - Construir imatge Docker
  ./do.sh start          - Iniciar servidor (en primer pla)
  ./do.sh start -d       - Iniciar servidor (en segon pla)
  ./do.sh stop           - Aturar servidor
  ./do.sh migrate        - Aplicar migracions
  ./do.sh makemigrations - Crear noves migracions
  ./do.sh shell          - Obrir terminal al contenidor
  ./do.sh check          - Validar configuració Django
